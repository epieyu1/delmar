# Sistema de diseño móvil · Del Mar Artesanías

El sistema visual traduce la composición de las interfaces interiores de la referencia a la web móvil de Del Mar. No contiene carcasa, mockup, fondo de póster ni elementos de sistema simulados. La adaptación se limita a reglas móviles; las pantallas anchas permanecen fuera de este rediseño.

## Tokens

| Token CSS | Valor | Uso |
|---|---|---|
| `--paper` | `#F5F0E8` | Fondo de pantalla |
| `--paper-warm` | `#FBF8F1` | Tarjetas y áreas claras |
| `--wine` | `#381626` | Hero y panel destacado |
| `--wine-deep` | `#29101D` | Contraste profundo del hero |
| `--coral` | `#E39A8D` | CTA y estado activo |
| `--sage` | `#DCE3D8` | Fondos secundarios |
| `--ink` | `#202725` | Texto principal |
| `--ink-soft` | `#69716C` | Descripciones |

Los valores aproximan los colores observados en el JPEG; no son mediciones exactas.

## Tipografía y tarjetas

- Titulares y controles móviles usan DM Sans/sans serif.
- Los nombres de producto aparecen completos; se permite que ocupen las líneas necesarias.
- Las tarjetas mantienen una proporción fotográfica consistente, una superficie cálida y sombra discreta.
- Una tarjeta de producto única se centra dentro de su sección.

## Composición

- **Cabecera:** marca y acciones reales del sitio.
- **Inicio:** hero vino a ancho completo, foto real, texto legible y borde orgánico; datos derivados del catálogo; tarjetas en dos columnas.
- **Artesanía:** contenido de pilares y filtros basados en categorías reales; las tarjetas comparten el mismo sistema del catálogo.
- **Historia:** fotografía y relato reales; insignia separada del subtítulo.
- **Catálogo:** título, búsqueda, filtros y tarjetas de dos columnas.
- **Contacto:** canales y ubicación ya registrados.
- **Navegación:** cinco destinos existentes en una barra inferior flotante; el destino activo se distingue con coral.

Los filtros se conservan en una fila cuando caben y pueden envolver a una segunda línea en pantallas más estrechas para que cada píldora permanezca visible. Los textos, fotos, precios y categorías se mantienen desde los datos de Del Mar.
